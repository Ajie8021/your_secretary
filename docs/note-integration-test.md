

## 1. 测试目的

验证随笔页面、`note` 云函数与云数据库 `notes` 集合的协同工作，确认满足设计约定：
CRUD、默认标题"无题"、置顶、排序（top 降序 + createTime 降序）、用户隔离、
受控字段不可被客户端覆盖、图片只存 fileID。

## 2. 测试环境

- 客户端：微信开发者工具（基础库版本：待填写）+ 真机（机型/系统：待填写）
- 后端：微信云开发 `note` 云函数
- 数据库：`notes` 集合；索引：`_openid(升) + top(降) + createTime(降)`
- 测试账号：至少 2 个不同 openid 的测试用户

## 3. 测试前置说明

- 云函数依赖云环境，纯函数（toNoteView / normalizePaging / isValidImages）以 Jest 单测覆盖；
  业务 action 通过云函数测试面板或页面交互 + 数据库核对验证。
- "用户隔离"用例需两个真实 openid；在测试面板无法伪造 OPENID，须用两个账号分别登录页面验证。

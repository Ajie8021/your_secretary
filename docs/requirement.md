# 需求分析文档

## 一、项目概述

**项目名称**：备忘秘书小程序
**项目定位**：主要面向大学生的学业与校园事务 DDL 提醒工具
**核心价值**：在备忘录基础上加入微信订阅消息提醒，解决“记了但忘记看、看到时已过 DDL”的问题
**项目性质**：个人练习项目，轻量、免费、无广告

------

## 二、目标用户

- **主要用户**：在校大学生
- **典型场景**：课程作业、学生工作、活动申请、考试报名等有明确截止时间的事务
- **用户特征**：微信高频使用，事务碎片化，易遗忘 DDL

------

## 三、功能需求

### 1. 登录

| 编号 | 需求                         | 优先级 |
| :--- | :--------------------------- | :----- |
| F1-1 | 微信授权登录，获取头像、昵称 | 必做   |

### 2. 用户端

#### （1）任务模块

| 编号 | 需求                                                         | 优先级 |
| :--- | :----------------------------------------------------------- | :----- |
| F2-1 | 任务列表展示：名称、类型标签、内容（一行/图片）、DDL、按重要程度（时间管理四象限）排序 | 必做   |
| F2-2 | 长按任务手动置顶/取消置顶                                    | 必做   |
| F2-3 | 任务查看：点击任务盒子，可以查看具体任务信息                 | 必做   |
| F2-4 | 添加任务：名称（默认“无名”）、类型标签（可自定义）、重要程度、截止时间（必填）、内容（必填，可传图） | 必做   |
| F2-5 | 保存时申请订阅消息授权，设置**单个**提醒时间                 | 必做   |
| F2-6 | 任务编辑、删除                                               | 必做   |

> 说明：时间管理四象限优先级按照重要且紧急、重要但不紧急、紧急但不重要、不重要也不紧急排序

#### （2）随笔模块

| 编号 | 需求                                                       | 优先级 |
| :--- | :--------------------------------------------------------- | :----- |
| F3-1 | 随笔列表：标题、正文（两行/图片）、记录时间，按时间排序    | 必做   |
| F3-2 | 长按置顶/取消置顶                                          | 必做   |
| F3-3 | 随笔查看：点击随笔盒子，可以查看随笔具体内容               | 必做   |
| F3-4 | 添加随笔：标题（默认"无题"）、正文（可传图），自动记录时间 | 必做   |
| F3-5 | 编辑、删除                                                 | 必做   |

#### （3）我的模块

| 编号 | 需求                                                     | 优先级 |
| :--- | :------------------------------------------------------- | :----- |
| F4-1 | 基础信息：头像、昵称、性别、出生日期、地址、职业，可修改 | 必做   |
| F4-2 | 反馈建议：填写提交，回复前可改，回复后置灰               | 必做   |
| F4-3 | 系统消息：接收管理端消息                                 | 必做   |
| F4-4 | 展示作者联系邮箱                                         | 必做   |

### 3. 管理员端

| 编号 | 需求                                 | 优先级 |
| :--- | :----------------------------------- | :----- |
| F5-1 | 管理员鉴权（admins 白名单 openid）   | 必做   |
| F5-2 | 查看用户反馈并回复                   | 必做   |
| F5-3 | 统计用户群体：性别、年龄、地域、职业 | 缓做   |

### 4. 拓展功能

| 编号 | 需求     | 优先级 |
| :--- | :------- | :----- |
| F6-1 | 手写功能 | 先不做 |

------

## 四、非功能需求

| 类别 | 要求                           |
| :--- | :----------------------------- |
| 平台 | 微信小程序                     |
| 主体 | 个人                           |
| 成本 | 零服务器、零备案、零运维       |
| 性能 | 列表加载流畅，云函数响应 < 1s  |
| 数据 | 用户数据隔离，管理员白名单鉴权 |
| 提醒 | 每个任务仅推送 1 条订阅消息    |

------

## 五、技术约束

| 约束       | 说明                                     |
| :--------- | :--------------------------------------- |
| 推送限制   | 一次性订阅消息，单任务仅推 1 条          |
| 定时任务   | 依赖云函数定时触发器                     |
| 管理员登录 | 复用微信登录，通过 admins 集合白名单区分 |

------

## 六、MVP 范围

**必做**：

- 微信登录
- 任务增删改查 + 时间管理四象限排序 + 置顶
- 任务订阅消息提醒（单条）
- 随笔增删改查 + 置顶
- “我的”页面的基础信息 + 系统消息
- 管理员端的用户反馈

**缓做**：

- 管理员端的统计

**不做**：

- 手写

------

## 七、技术栈

- **前端**：原生小程序 + Vant Weapp
- **后端**：微信云开发（云函数 / 云数据库 / 云存储 / 定时触发器 / 订阅消息）
- **鉴权**：openid + admins 白名单

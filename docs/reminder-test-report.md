# 提醒模块集成测试报告

## 1. 测试目的

验证任务提醒从"配置 → 订阅授权 → 定时扫描 → 发送 → 状态回写 → 修改/关闭生效"的完整链路，
确认符合设计约定：单任务单条设计、仅发送成功才标记 `reminded=true`、修改/关闭提醒后旧配置不生效、
并发扫描不重复发送、单条失败不阻断整批。

## 2. 测试环境

- 客户端：微信开发者工具（基础库版本：`wx-server-sdk` 3.0.0）+ 真机（机型/系统：window 11）
- 后端：微信云开发 `task`、`sendReminder` 云函数
- 数据库：`tasks` 集合
- 定时触发器：`sendReminder` 每分钟触发（触发器配置："0 */1 * * * * *"）
- 订阅消息模板：模板 ID（`Qq%vE`）、字段映射（任务名称/截止时间）
- 测试账号：至少 2 个不同 openid 的测试用户

## 3. 测试前置说明

- 订阅消息为一次性订阅，真机下发需用户对每次授权实际点击允许；开发者工具无法完整模拟真实下发。
- `sendReminder` 为定时触发，测试时可通过云开发控制台手动触发或临时调整触发频率加速验证，
  测试完成后必须恢复正式触发配置。
- 涉及"发送失败"的用例，通过构造无效模板 ID、无授权记录、模拟接口错误等方式触发。

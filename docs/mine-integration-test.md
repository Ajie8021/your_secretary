# “我的”模块集成测试报告

## 1. 测试目的

验证“我的”入口、基础资料、用户反馈与系统消息入口，确认满足设计约定：
资料白名单更新、受控字段不可被客户端覆盖、反馈仅本人可见、未回复可修改、已回复拒绝修改（409）、
系统消息入口展示反馈回复、图片只存 fileID、作者邮箱可复制。

## 2. 测试环境

- 客户端：微信开发者工具（基础库版本：待填写）+ 真机（机型/系统：待填写）
- 后端：微信云开发 `user`、`feedback` 云函数
- 数据库：`users`、`feedbacks` 集合
- 测试账号：至少 2 个不同 openid 的测试用户
- 说明：管理员回复由第 6 阶段提供；本阶段“已回复”用例可通过控制台手工写入 `reply`/`repliedAt` 构造

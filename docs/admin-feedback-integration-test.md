# 管理员反馈管理模块集成测试报告

## 1. 测试目的

验证 `admin` 云函数与 `pages/admin/feedback` 管理页，确认满足设计约定：
每次管理操作云函数侧重新鉴权（admins 白名单）、非管理员无法读取/修改管理数据、
管理员可分页查看全部反馈、回复写入 reply/repliedAt 且一条反馈只允许回复一次、
回复后用户侧置灰不可改、系统消息入口可见回复、入口隐藏仅作展示不作安全措施。

## 2. 测试环境

- 客户端：微信开发者工具（基础库版本：待填写）+ 真机（机型/系统：待填写）
- 后端：微信云开发 `admin` 云函数
- 数据库：`admins`、`feedbacks` 集合
- 测试账号：至少 1 个白名单管理员、2 个普通用户（不同 openid）
- 前置：`admins` 集合已手工插入管理员 openid；`feedbacks` 集合存在

## 4. 测试结论

- 单测通过数 / 总数：5/5
- 遗留风险：
  - 管理员白名单为手工维护，误删/误加无审计；
  - 回复一次后不可再编辑，若回复内容有误需线下处理（本期规则）；
  - 管理页与用户页样式为两份文件，后续改动需同步（或抽公共样式）。
